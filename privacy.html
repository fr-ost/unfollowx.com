This policy describes the UnfollowX Pro Chrome extension, version 7.3.4, and this website.

In short: UnfollowX Pro does not ask for your X password. Your X lists, whitelist, scan results and action history are stored in Chrome extension storage. The extension also includes optional anonymous usage statistics, enabled by default, which you can turn off in Settings.

What the extension does

UnfollowX Pro helps you review your X following and followers lists and, when you choose, follow or unfollow accounts. It works in your browser with the X session you are already signed into. It does not request your X password or sign in for you.

To read lists and perform actions, the extension sends requests to X itself on x.com or twitter.com. It may read X app resources from abs.twimg.com. It does not send your X lists or action history to the developer’s telemetry service.

Information stored on your device

The extension uses Chrome storage to save the information needed for its features. This can include:

  • Settings such as speed, daily limit, Keep rules, language and notification preferences.
  • Your whitelist, scans, following and follower snapshots, and follower changes between saved checks.
  • First-seen dates, scan totals, last-active results and saved groups.
  • Local follow/unfollow history, action counters and job progress.
  • A random installation identifier and telemetry preference.

When you use multiple X accounts, the extension keeps account-specific scan and history data separately on your device. You can remove the data from Dashboard → Settings → Delete all extension data, or remove the extension in Chrome.

Optional anonymous usage statistics

Anonymous usage statistics help the developer understand installs and active use and investigate product issues. The extension’s telemetry code sends an install event and, at most once a UTC day when active, an event containing a random install ID generated on your device, extension version, event type and timestamp. The active event also includes an aggregate count of follow and unfollow actions during the previous 24 hours. An uninstall beacon includes the install ID and extension version. The server derives a coarse country from the network request.

The extension states that these events do not include your X username or account ID, following or follower lists, whitelist or action history. The telemetry request omits browser credentials. The extension’s privacy disclosure says the network IP is not stored; the extension code itself cannot verify server-side retention practices.

Statistics are enabled by default. You can disable them in Dashboard → Settings → Privacy → Anonymous usage stats. When disabled, the extension stops sending these events and clears the uninstall URL. The extension’s random ID is stored locally and resets when you clear extension data.

Why the extension requests permissions

  • x.com and twitter.com: read your lists and perform follow/unfollow actions in your signed-in browser session.
  • abs.twimg.com: read X app resources used to understand how the website works.
  • storage and unlimitedStorage: keep settings, scans and history locally.
  • alarms: schedule action delays, breaks and daily-limit pauses.
  • scripting: start work in an already-open X tab without requiring a reload.
  • notifications (optional): show local desktop alerts if you enable notifications.

Your choices

You can switch off anonymous statistics, delete extension data, decline optional notifications and stop an action run at any time. Removing the extension also removes its local storage through Chrome’s extension lifecycle.

This website

This static marketing website does not require an account and does not include first-party analytics, advertising trackers or a newsletter form. Links to the Chrome Web Store and support services are operated by those providers and are subject to their own privacy practices. Hosting provider logs may be processed to serve and secure the website.

Children

The extension is not directed at children under 13. The developer does not knowingly collect personal information from children.

Plenty of people run more than one X account: a personal account and a work one, a brand and its founder, or a few client accounts. Chrome gives you two good ways to handle this — X’s built-in account switcher and separate Chrome profiles — and the right choice depends on how often you switch and how strictly you want to keep accounts apart.

## Option 1: X’s account switcher

X lets you [add and switch between several accounts](https://help.x.com/en/managing-your-account/managing-multiple-x-accounts) in the same browser. On x.com, open the account menu at the bottom of the left sidebar and choose **Add an existing account**, then sign in. Afterwards, the same menu switches between accounts in a click.

**Good for:** switching a few times a day between accounts you manage yourself.
**Trade-off:** all accounts share the same browser, extensions and history, so it’s easy to post or act from the wrong account if you’re not paying attention.

## Option 2: One Chrome profile per account

Chrome profiles are separate browser identities, each with its own cookies, history, bookmarks and extensions. Signing in to a different X account in each profile keeps them completely apart, and you can open profiles side by side in separate windows with different colours and names. Chrome’s help explains [how to add and switch profiles](https://support.google.com/chrome/answer/2364824).

**Good for:** accounts that must never mix — clients, a brand and a personal account, or accounts used by different people.
**Trade-off:** you install extensions per profile, so a tool you use in one profile needs to be added to the others.

| | X account switcher | Separate Chrome profiles |
| --- | --- | --- |
| Setup | A minute | A few minutes per profile |
| Switching | One click inside X | Switch window or profile |
| Accounts visible at once | One at a time | Several, side by side |
| Extensions and their data | Shared | Separate per profile |
| Risk of acting as the wrong account | Higher | Lower |

## Managing following lists across accounts with UnfollowX Pro

[UnfollowX Pro](/features) supports multiple X accounts in either setup.

**With X’s account switcher (one Chrome profile):** the extension keeps each X account’s data separate — its scan, whitelist, history, saved groups and daily action count. When you switch to another account on X, that account’s data loads automatically. It never switches in the middle of a run, so a cleanup for one account can’t spill into another. In **Settings**, you can see the accounts the extension has saved and delete one account’s data without affecting the others.

**With separate Chrome profiles:** install UnfollowX Pro in each profile. Each installation has its own extension storage, settings and daily count.

> [!TIP] Before any bulk action, glance at the account name in the UnfollowX Pro popup. It shows the signed-in X account, its handle and its daily count, so you always know which account you’re about to act on.

## Habits that prevent mix-ups

- **Name and colour your profiles** clearly in Chrome (for example “Brand — red”, “Personal — blue”).
- **Keep separate whitelists.** A friend you protect on your personal account may not matter to your brand account, and the reverse.
- **Pace each account independently.** X applies [follow limits](https://help.x.com/en/using-x/x-follow-limit) to each account; UnfollowX Pro’s daily limit is tracked per account too.
- **Export before big changes.** A CSV of each account’s following list is a cheap backup — see [how to export your X following list](/blog/how-to-export-your-x-following-list-to-csv).
- **Sign out of accounts you no longer manage.** Old sessions are easy to forget in a shared browser.

## Frequently asked questions

### How many X accounts can I add to the switcher?

X sets the number. Check X’s [help page on managing multiple accounts](https://help.x.com/en/managing-your-account/managing-multiple-x-accounts) for the current details.

### Can I merge two X accounts?

No. X doesn’t offer a way to merge accounts or move followers between them.

### Does UnfollowX Pro mix data between accounts?

No. Scans, whitelists, history, groups and daily counts are stored per X account, and switching accounts never happens mid-run.

## The bottom line

Use X’s account switcher if you manage a couple of accounts yourself and switch often. Use separate Chrome profiles when accounts must stay strictly apart. Either way, keep a separate whitelist and pace for each account, and check which account is active before any bulk change.

Quick help with getting started, reviewing accounts, managing actions and understanding privacy.

UnfollowX Pro is a Chrome extension for reviewing your X following list. It can identify non-followers, track changes between follower checks, filter accounts and help you manage follow or unfollow actions.
Install UnfollowX Pro from the Chrome Web Store, open x.com in Chrome and run a scan from the extension. Review the “Don’t follow back” results before selecting any action.
Run a followers check to save a baseline, then check again later. The extension compares complete snapshots and lists accounts that are new or no longer present. It cannot reconstruct changes from before your first snapshot.
The extension supports x.com and twitter.com in Google Chrome. X may change its website, so compatibility can change over time.
No. It uses the X session you already have open in Chrome. It does not request or store your X password.
The extension stores settings, scan data, whitelist, follower snapshots, groups and action history in Chrome extension storage on your device. Its privacy policy explains the optional anonymous usage events separately.
If enabled, the extension sends an install identifier, extension version and event information such as install or daily activity; active events include an aggregate follow/unfollow action count. The extension states that it does not send your X account or lists. You can turn this off in Dashboard → Settings → Privacy → Anonymous usage stats. See the privacy policy.
Yes. Review the scanned list, search or filter it, then select individual accounts or a group. Whitelist and Keep rules are applied to supported bulk cleanup modes. Check your selection before starting.
Yes. You can pause, resume or stop. The extension supports action delays, breaks and a rolling daily limit. X may still rate-limit or restrict activity, so use reasonable settings and stop if X shows a warning or verification request.
The extension keeps a local history of accounts it has unfollowed. You can select an account in History and follow it again, subject to X’s current behavior and limits.
The extension is free to install and use, and it does not require a separate UnfollowX account. The Chrome Web Store listing is the source for current availability and version details.
Use Dashboard → Settings → Delete all extension data, or remove the extension from Chrome. This deletes the local extension data associated with it.
The package is a Chrome extension (Manifest V3). The interface currently includes English, Spanish, Portuguese (Brazil), Hindi, Indonesian, Turkish and Arabic.
